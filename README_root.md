## Projects

### 1. [Election Outcome Prediction & Presidential Speech Text Analysis (NLP)](./election-prediction-nlp)
Built and compared six classification models (Logistic Regression, LDA, Naive Bayes, KNN, Bagging with Random Forest, AdaBoost, Gradient Boosting) to predict voter party choice from survey data of 1,525 voters, tuning hyperparameters via GridSearchCV and evaluating with ROC-AUC. Also applied NLP preprocessing (tokenization, stopword removal, word-frequency analysis) using NLTK on three U.S. presidential inaugural speeches.
**Tools:** Python, scikit-learn, NLTK, Pandas, Matplotlib/Seaborn

### 2. Predictive Modelling for Tourism Package Targeting
Applied logistic regression and linear discriminant analysis to predict customer purchase likelihood; improved precision using Bagging and Random Forest classifiers to optimize product-price combinations.
**Tools:** Python, scikit-learn, Pandas

### 3. Statistical & Probabilistic Analysis of Multi-Source Data
Analyzed store sales, university survey, and manufacturing datasets using descriptive statistics, probability distributions, and hypothesis testing to draw actionable business inferences.
**Tools:** Python, SciPy, Pandas

### 4. Gems Price Prediction & Holiday Package Analysis
Used linear regression to predict gemstone pricing across multiple variables, supporting a profit-maximization strategy.
**Tools:** Python, scikit-learn, Pandas

### 5. Visualizing Insurance Claims — Tableau Dashboards
Built interactive Tableau dashboards delivering high-level insights and performance metrics to an insurance company's leadership team, enabling data-driven policy decisions.
**Tools:** Tableau
